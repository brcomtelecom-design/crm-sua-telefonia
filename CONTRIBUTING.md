# Contribuindo com o CRM Sua Telefonia

Obrigado pelo interesse em contribuir com este projeto open source.

## Como contribuir

- Reporte problemas pela aba Issues.
- Sugira melhorias e novas funcionalidades.
- Faça um fork do repositorio.
- Crie uma branch para suas alteracoes.
- Execute os testes com npm test.
- Envie um Pull Request descrevendo as alteracoes.

## Seguranca e privacidade

Nunca publique senhas, tokens, chaves privadas,
sessoes do WhatsApp ou dados reais de clientes.

Utilize dados ficticios durante os testes.

## Licenca

As contribuicoes ao projeto sao disponibilizadas
sob os termos da licenca MIT.

## Tecnologias

- Node.js
- JavaScript
- SQLite
- HTML e CSS
- WhatsApp Business API

Contribuicoes da comunidade sao bem-vindas!
